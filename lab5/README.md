# Tampa Bay Vessel Flow Map

## Study Area and Dates:
For my assignment I decided to focus on Tampa Bay in Florida, from January 1, 2023 to January 8, 2023. I decided to choose Tampa Bay because I wanted to learn more about the vessel activity in the area. I knew that its a highly populated area that is also near an Air Force Base (MCF - Macdill Air Force Base), so I thought my map would show a lot of activity between each vessel type. I used AcccessAIS as my data source which provided all the data used in my map. I chose the time range because I wanted to specifically gain insight on how vessel activity flowed within one week of time. The timezone in Tampa Bay is Eastern Standard Time.
